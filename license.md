The MCP Server Software is designed strictly as a dynamic, real-time grounding interface to retrieve live geospatial intelligence from Mappls-MapmyIndia APIs. Under no circumstances may the MCP Server Software or the data returned through its tools be used to diminish or replace the ongoing need for live Mappls grounding queries.

Except with the express, prior written authorization of MapmyIndia pursuant to a separate enterprise agreement, you shall NOT, and shall not permit or assist any third party, model provider, consuming application, or LLM agent to:

1. **Model Training & Fine-Tuning:** Use, ingest, or extract any outputs, responses, tool-call results, coordinates, metadata, geocodes, routing paths, or location insights generated by or received through the MCP Server Software (collectively, “Geospatial Outputs”) for the purpose of training, pre-training, fine-tuning, distilling, RLHF (Reinforcement Learning from Human Feedback), alignment, or training-data synthesis of any Artificial Intelligence (AI), Machine Learning (ML), Large Language Model (LLM), Small Language Model (SLM), or autonomous agent.
2. **Persistent Caching & Vector Database Scraping:** Store, cache, harvest, scrape, index, or retain Geospatial Outputs in persistent local or distributed vector databases, embedding stores, semantic caches, RAG (Retrieval-Augmented Generation) corpora, or offline data stores for the purpose of circumventing future API calls, reducing billable query volumes, or serving repeated queries without invoking the live Mappls MCP server. Volatile, in-memory context retained strictly within the lifecycle of a single, active conversation session is permitted solely to formulate an immediate user response.
3. **Synthetic Dataset Generation:** Generate synthetic datasets, algorithmic ground truths, evaluation benchmarks, or mock geospatial repositories derived from Geospatial Outputs to build, train, or validate alternative location, search, geocoding, routing, or mapping models.
4. **Proxy Services & Model Re-hosting:** Expose the MCP Server Software or its derived tool capabilities as a third-party intermediary, unified gateway, or public proxy intended to mask downstream end-user query volumes or resell Mappls data under another service identity.
